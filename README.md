# Snake

Classic Snake game implementation developed as an early programming project.

## Overview

A recreation of the classic Snake game, featuring player movement, food collection, score progression, and collision detection mechanics.

## Features

- Snake movement
- Food spawning
- Score tracking
- Collision detection
- Increasing difficulty

## Technologies

- C
- POSIX Threads
- Ncurses

## Historical Relevance

One of my early game development projects, exploring gameplay programming, event handling, game loops, and interactive application development.
